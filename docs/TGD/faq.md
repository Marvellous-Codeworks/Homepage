# What do you want to know?

## Is The Great-_er_ Tab Discarder open source?

**Yes**. The code is [publicly available on GitHub](https://github.com/rkodey/the-great-er-discarder-er).

## Is TGD compatible with Chromium browsers?

The primary distribution channel is the Chrome Web Store, but the addon is also officialy available for Microsoft Edge.  
For compatible Chromium browsers, verify installation and supported policies case by case.
